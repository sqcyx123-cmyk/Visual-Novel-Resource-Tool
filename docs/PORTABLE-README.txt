视觉小说资源工具

启动：双击“视觉小说资源工具.exe”。
日常使用和分享使用同一个文件夹。分享时复制或压缩整个“视觉小说资源工具”文件夹，请勿仅发送 EXE，也不要删除 third_party。

运行环境
- Windows 10/11，x64；已包含 .NET 运行时，不需要安装 .NET SDK 或访问源码目录。
- 图片识别、支持的资源提取及 EXE 解包所需组件已经包含。
- 视频动态预览需要额外安装 FFmpeg，使 ffmpeg.exe 可以从 PATH 找到；缺少它仍可提取原视频。
- RPyC 反编译需要兼容的 Python 3；程序会搜索所选游戏附带的 Python 和 PATH。未包含游戏或本机 Python 环境。

个人数据
- 设置和拖出缓存存放在当前 Windows 用户的 %LOCALAPPDATA%\视觉小说资源工具，更新软件时保留，不需要分享。
- 提取结果存放在界面显示的输出位置，默认是所选游戏的“解包结果”目录。
- 程序不需要账号登录。请勿自行把游戏素材、设置、密钥或其他个人文件放入软件文件夹后发送。

更新：关闭程序，由维护脚本更新此固定文件夹；已有桌面快捷方式不需要变更。
